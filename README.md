## 🚀 Server Admin Practice Lab

Hands-on Linux administration practice project created as part of my Cloud Engineering journey.

### 📚 Concepts Practiced
- Linux file & folder management
- Navigation commands
- File permissions (`chmod`)
- Process management
- Shell scripting basics
- Environment variables
- Log monitoring with `tail -f`
- Backup handling
- Git & GitHub workflow

---

### 📁 Project Structure

```text
linux-foundation-labs/
├── backups/
├── configs/
├── logs/
├── scripts/
└── README.md
```

---

### ⚙️ Included Files

#### `configs/app.conf`
Practice configuration file.

#### `logs/system.log`
Used for log monitoring and log-reading practice.

#### `scripts/monitor.sh`
Simple monitoring script that displays:
- current user
- current directory
- current date/time
